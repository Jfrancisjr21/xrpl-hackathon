# Technical report

Confiance is an underwriting desk for loan brokers on the XRPL lending protocol (XLS-65 vaults, XLS-66 loans). Every action is a real Devnet transaction. Stack: a TypeScript pnpm monorepo with a React web app, an Express API on SQLite, a shared Zod contract, a ledger package on xrpl.js and a risk package. Depositors fund a private vault in TSTUSD, an MPT token. Borrowers apply; the risk pipeline checks the address against a local OFAC SDN list, scores it 0-100, applies policy and prices the rate. A human broker approves, then the API originates the loan with LoanSet and stores a SHA-256 hash of the full decision on-chain, so anyone can verify it. A monitor flags overdue payments, and the broker can impair or default. The platform earns the management fee. AI writes only the explanation, never the decision. Limits: Devnet only, the server holds the demo keys, and credit data is made up.
